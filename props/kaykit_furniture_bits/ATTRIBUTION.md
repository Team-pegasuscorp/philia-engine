# KayKit — Furniture Bits

Asset tiers, non créé par ce projet.

- **Pack** : Furniture Bits (v1.0, 2023), ~53 meubles/objets d'intérieur
  (fauteuils, lits, étagères, tables, cactus, tableaux, tapis...)
  par Kay Lousberg
  https://kaylousberg.com/

**Licence : CC0 1.0 Universal** (domaine public, aucune attribution
requise — créditer Kay Lousberg est apprécié mais pas obligatoire)
https://creativecommons.org/publicdomain/zero/1.0/

Format glTF repris tel quel (chaque `.gltf` + `.bin` + la texture
partagée `furniturebits_texture.png`, tous dans ce dossier — les .gltf
y référencent la texture par chemin relatif, donc ne pas la déplacer
séparément). Le pack original fournit aussi FBX/OBJ, pas repris ici.
